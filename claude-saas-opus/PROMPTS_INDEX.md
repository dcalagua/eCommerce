| P03 | PIM: variantes, atributos, UoM y bundles |

| P05 | Customers, segmentos y foundation B2B |
| P06 | Inventario multi-almacén, ATP y reservas concurrentes |
| P07 | Carrito persistente y Checkout Pipeline idempotente |
| P08 | OMS, snapshots, transiciones y timeline |
| P09 | Payments abstraction, webhooks y conciliación base |
| P10 | Promotions Engine, cupones y gift cards |
| P11 | CMS, white-label, búsqueda y merchandising |
| P12 | Fulfillment, logística, tracking y returns |
| P13 | Analytics, auditoría y observabilidad |
| P14 | API enterprise, webhooks e Integration Monitor |
| P15 | Storefront performance, accesibilidad y SEO |
| P16 | Security baseline y enterprise readiness |
| P17 | Quality Gate final y release baseline |

El supervisor no cuenta como fase: se invoca automáticamente solo cuando una fase falla o no supera el gate independiente del runner.
